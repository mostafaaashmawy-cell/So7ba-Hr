# HumAi — موقع التسويق والتعريف بالمنصة (Marketing Website)

الموقع التسويقي الرسمي لمنظومة **HumAi** — نظام إدارة الموارد البشرية والرواتب الذكي المدعوم بمساعد ذكاء اصطناعي عبر واتساب، والمصمم خصيصاً للشركات الصغيرة والمتوسطة في مصر والشرق الأوسط.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Next.js 15 (App Router)** + **TypeScript**
- **Tailwind CSS**
- **خط IBM Plex Sans Arabic** (عبر `next/font/google`)
- **Lucide React Icons** للأيقونات
- **دعم كامل للتوجيه من اليمين إلى اليسار (RTL)**

---

## 🚀 طريقة التشغيل محلياً (Local Development)

1. **تثبيت الحزم (Dependencies):**
   ```bash
   npm install
   ```

2. **تشغيل خادم التطوير:**
   ```bash
   npm run dev
   ```
   افتح المتصفح على الرابط: [http://localhost:3000](http://localhost:3000)

3. **بناء المشروع للإنتاج (Production Build):**
   ```bash
   npm run build
   npm run start
   ```

## 🧭 هيكل الصفحات والمسارات (Routes)

| المسار (Route) | اسم الصفحة | الوصف |
| :--- | :--- | :--- |
| `/` | **الصفحة الرئيسية (Home)** | الهيرو، أرقام الثقة، ركائز النظام، محاكي واتساب، جدول المقارنة، آراء العملاء، والأسئلة الشائعة. |
| `/blueprints` | **قوالب التشغيل (Blueprints)** | استعراض قوالب الشركات الخدمية، المحلات والتجزئة، والشركات الناشئة مع مميزات التفعيل. |
| `/whatsapp-assistant` | **مساعد واتساب الذكي** | محاكي محادثة واتساب التفاعلي، استعلامات الحضور والرواتب، والأمان وعزل البيانات. |
| `/pricing` | **الأسعار والباقات** | جدول مقارنة الباقات (Starter، Growth، Enterprise) وأسئلة الأسعار الشائعة. |
| `/security` | **الأمان والخصوصية** | محاور حماية وعزل البيانات (Multi-Tenant)، التشفير، الصلاحيات، والتأكيد المزدوج. |
| `/contact` | **تواصل معنا / احجز عرضاً** | نموذج تفاعلي لحجز عرض توضيحي لمدة 30 دقيقة مع التحقق الفوري ورابط واتساب المباشر. |
